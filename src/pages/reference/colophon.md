---

- **Static and fast.** Every page is plain HTML generated ahead of time. There are no trackers and no third-party scripts.
- **Works offline.** Pages you have visited stay readable without a connection.
- **Self-hosted type.** Text is set in Source Serif 4, with labels in IBM Plex Mono, both served from this site rather than a font service.
- **Written in plain text.** Every lecture, journal entry and research page is a Markdown file, so none of it is locked into a platform.
- **Built to print.** Any page prints as a clean document, with margin notes gathered as footnotes.
